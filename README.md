# Guin-16
The Guin-16 is a 16-bit CPU made for my senior capstone project at Youngstown State University. It features a custom instruction set inspired by the 6502 processor, 7 register, 5 flags, and 16 bits of address space in RAM. You can find in-depth information about how the Guin-16 works and the instruction set on the [website](https://shogrenjacob.github.io/16-bit-cpu/).
