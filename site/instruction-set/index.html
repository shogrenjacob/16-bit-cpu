    Instruction Set

    For any non-data word, the center two hex digits of data at a memory address represent a given opcode. The first hex digit (from left to right) represents the addressing mode to use, and the last hex digit represents what flags to compare during instruction processing.

    For example, x4021 in memory tells the CPU to perform a LDA (0x02) using the next word in memory as an Absolute (0x4) address, and to check whether or not the zero flag is raised (0x1).

    NOP

    Do nothing, but increment the program counter.

    Addressing Mode Opcode Cycle Cost
    Implicit x000 1

    Processor Status Changes:

    • Carry: No change.
    • Zero: No change.
    • Overflow: No change.
    • Parity: No change.
    • Negative: No change.

    LDA

    Load the next data word into the Accumulator.

    Addressing Mode Opcode Cycle Cost
    Immediate x002 2
    PageAhead x502 3
    PageBehind x202 3
    Absolute x402 3
    AbsoluteX x102 3
    AbsoluteY x602 3

    Processor Status Changes:

    • Carry: No change.
    • Zero: Raise if Accumulator = 0.
    • Overflow: No change.
    • Parity: Raise if bit 0 of the Accumulator is up.
    • Negative: Raise if bit 15 of the Accumulator is up.

    JMP

    Jump to the memory location given by the processed data word.

    Addressing Mode Opcode Cycle Cost
    Immediate x052 2
    PageAhead x566 3
    PageBehind x266 3
    Absolute x467 3
    AbsoluteX x166 3
    AbsoluteY x666 (Spooky!) 3
    Indirect x766 1

    Processor Status Changes:

    • Carry: No change.
    • Zero: No change.
    • Overflow: No change.
    • Parity: No change.
    • Negative: No change.

    JMPP

    Jump to the start of the page given by the page register.

    Note: The page register stores the page number of the page to jump to, not the address at the start of the page. So, a page register holding a value of 1 will jump to 0xff in memory.

    Addressing Mode Opcode Cycle Cost
    Implicit x056 1

    Processor Status Changes:

    • Carry: No change.
    • Zero: No change.
    • Overflow: No change.
    • Parity: No change.
    • Negative: No change.

    Note on Branch Instructions:

    The extra hex digit in the opcode represents the flag to check for the conditional branch. Theoretically, you can use 2, 4, 8, and f as the last digit to use different flags as conditionals but that is not officially supported in the instruction set.
